# WorkFlowOS - Product Requirements

## Vision

Centralize company work, tasks, requests, incidents, approvals, workflows, SLA, notifications, and audit activities in a single enterprise platform.

## User Personas

| Role       | Description                                  | Key Actions               |
|------------|----------------------------------------------|---------------------------|
| Employee   | Day-to-day worker submitting requests/tasks   | Create requests/tasks    |
| Team Lead  | Leads a functional team                       | Approve, assign tasks    |
| Manager    | Manages department-level work                 | Approve, oversee metrics |
| IT Team    | Handles technical incidents/requests          | Resolve, escalate        |
| HR         | Processes HR-related requests                 | Approve HR requests      |
| Finance    | Process financial requests                    | Approve finance requests |
| Admin      | Full system access                            | Configure workspace      |

## Core Modules

1. **Dashboard** - At-a-glance operational overview
2. **Users** - Directory and profile management
3. **Teams** - Group-based access and assignment
4. **Projects** - Container for related tasks
5. **Tasks** - Trackable work items
6. **Requests** - Structured internal requests
7. **Incidents** - Operational issue tracking
8. **Approvals** - Workflow approval system
9. **SLA** - Service level management
10. **Notifications** - Real-time alerts
11. **Audit Log** - Immutable activity trail
12. **Settings** - Workspace configuration

## Language Policy

- UI text: Bahasa Indonesia
- Technical terms remain English: Dashboard, API, SLA, RBAC, JWT
- Example: "Kelola seluruh pekerjaan dalam satu Dashboard."
